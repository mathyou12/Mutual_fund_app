# Mutual Fund Investment Backend

This project implements the backend for a Mutual Fund investment platform as per the shared requirement document.

## Features Completed
- Mutual fund listing
- Lump sum investment
- SIP (monthly) with pause/resume
- Portfolio tracking
- Fund performance analytics (benchmark, category average, alpha)

## Tech Stack
- Python
- FastAPI
- SQLite
- SQLAlchemy

## How to Run
```bash
pip install -r requirements.txt
python -m uvicorn main:app --reload
